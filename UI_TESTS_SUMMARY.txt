│ THE ROOT CAUSE                                                        │
└──────────────────────────────────────────────────────────────────────┘

  [{"id": 1, "name": "Bank 1"}, {"id": 2, "name": "Bank 2"}]

Frontend was expecting:
  {"banks": [{"id": 1, "name": "Bank 1"}]}

Result: Empty dropdowns everywhere!

Fix: Check if array, use directly:
  setBanks(Array.isArray(response.data) ? response.data : []);
